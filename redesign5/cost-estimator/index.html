[METHOD] Read the range correctly

A planning tool.
A better first brief.

The number is a range, not a fixed offer. The project information determines what the final quotation needs to include.

[01] / Quantity

Measure the right area.

Ceilings use room length × width. SFS and partitions use total wall run × average wall height, or a known measured area.

[02] / Allowance

Understand the rate.

The profile sets an indicative baseline. Scale, interfaces, height, site conditions, region and partition finish adjust the range.

[03] / Review

Check the project scope.

Performance, system build-up, design responsibilities, access, programme and specific inclusions or exclusions need project review.

[04] / Quotation

Share the information.

Use the brief alongside drawings and specification. A confirmed price follows the commercial review of the actual package.
