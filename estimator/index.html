Before you calculate

THE INPUTS HAVE TO MEAN SOMETHING.

The calculator follows the package logic used by the earlier GWG estimator, but treats validation and disclosure as part of the tool itself. Use measured or genuinely expected quantities; do not use the output as a substitute for drawings, specification or a tender review.

[01]Ceilings use net ceiling area.
[02]SFS and partitions use wall run × average height when area is not known.
[03]Specification, interfaces, access, height, region and finish move the allowance; programme constraints beyond out-of-hours work remain a project-review gate.

[03]Add the site conditions.

Method / how to read the output

THE RANGE IS A STARTING POINT, NOT THE FINISH LINE.

A useful planning tool tells you what went into the number and where the number is deliberately limited. The final quotation remains tied to the project information and the responsibility boundaries of the actual package.

[01] / Quantity

Measure the installed work.

Ceilings use ceiling area. SFS and partitions can use wall run × average height when a measured area is not already available.

[02] / Specification

Choose the closest documented build-up.

System profile, performance, interface density and—where relevant—finish are part of the planning allowance.

[03] / Conditions

Account for how the package reaches site.

Working height, occupied or restricted access, location and out-of-hours constraints change delivery conditions.

[04] / Review

Take the range back to the project information.

Drawings, specification, programme, exclusions, interfaces and responsibility boundaries determine the actual quotation route.
