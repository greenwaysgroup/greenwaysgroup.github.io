Delivery / Tender to completion

The detail starts before the site.

A defined package is easier to coordinate. Establish the scope, the interfaces and the information required at each stage of the work.

01 / Working sequence

From information
to installation.

  1. 01Tender

    Define the package

    Start with drawings, specification, quantities and programme. Identify the system, the boundaries of the package and the information still to be agreed.

    Drawings · specification · scope allocation

  2. 02Coordination

    Resolve the interfaces

    Review levels, openings, access and adjoining trades. Confirm the information needed at structure, services, façade and partition junctions before work is concealed.

    Setting out · junctions · responsibility

  3. 03Site delivery

    Sequence the installation

    Align the agreed work with access, working areas and the project programme. Keep installation tied to the issued details and the selected system.

    Access · work fronts · installation sequence

  4. 04Completion

    Close out the work

    Agree inspection points and the package records required by the project team. Address the finish, outstanding items and the scope of handover information.

    Inspection · finish · package records

02 / Tender information

A useful
starting brief.

Send enough information to understand the package and its place in the programme. If a detail is unresolved, identify it as an open item.

  1. 01Project name and location
  2. 02Relevant ceiling, SFS, partition or plastering package
  3. 03Current project or tender stage
  4. 04Programme or return dates
  5. 05Your company, role and contact details

Include the relevant drawings, specification and measured quantities where available. Confirm access constraints, working hours, adjoining trades and the intended responsibility for design and supply.

Common questions

Can we contact GWG at tender stage?

Yes. GWG accepts tender-stage and live-project enquiries. Send the project location, relevant package, current information, programme and return date so the next discussion can be specific.

Does GWG design the framing system?

GWG installs framing to issued project designs. Engineering, system selection and design responsibility must be allocated in the contract. Do not assume that installation scope includes design or façade responsibility.

How are fire and acoustic requirements addressed?

They must be tied to the selected system, its documented build-up and the approved junction details. Generic service descriptions and project photographs do not establish a performance rating.

Is the cost estimator a quotation?

No. It provides an early planning range using the website's existing assumptions. Final pricing requires a review of drawings, specification, quantities, access, programme and site conditions.
