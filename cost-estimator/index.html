Cost estimator / project information

START WITH SCOPE, QUANTITY AND PROGRAMME — NOT A MADE-UP UNIT RATE.

Important

This route prepares an initial commercial brief. It does not create a quotation, contract price or binding estimate without review of the actual project information.

Why this is structured

A PACKAGE PRICE DEPENDS ON THE PACKAGE.

Ceiling, framing and partition work cannot be priced responsibly from floor area alone. System build-up, heights, geometry, access, interfaces, finishes, programme and responsibility boundaries can materially change the work. The form below creates a concise brief for human review.

[01]

System / package

Identify whether the enquiry concerns suspended ceilings, SFS, partitions and plastering, or a coordinated combination.

[02]

Project location

Location affects logistics, access and the practical context of the package.

[03]

Approximate quantities

Share m², linear metres, room counts or other measured information if it is already available.

[04]

System build-up

Grid or MF ceiling, partition type, board layers, framing specification and related details matter more than a generic unit rate.

[05]

Programme

Tender return, start, duration and sequencing constraints are part of commercial review.

[06]

Project information

Drawings, specifications, schedules and revisions let the package be understood against the actual project rather than assumptions.
